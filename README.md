# Flyme Tweak (LynkCo Overlay App)

Это полностью переписанное, чистое Android-приложение для автомобильных магнитол (например, LynkCo). Оно создает на экране удобную плавающую кнопку-оверлей, которая позволяет быстро запускать выбранные вами приложения или управлять окнами.

## 🌟 Основные функции

* **Плавающая кнопка (Quick Launch):** Постоянная кнопка-меню для быстрого доступа к выбранным программам из любой точки системы.
* **Контекстная кнопка разворота (Fullscreen Toggle):** Кнопка появляется *только* поверх тех приложений, которые вы выбрали в настройках. Она позволяет принудительно разворачивать их на полный экран (передавая параметр `LaunchDisplayId = 1003`). Иконка кнопки меняется в зависимости от состояния экрана (`<>` или `><`).
* **Раздельные настройки:** Каждая кнопка имеет свои независимые настройки расположения (Слева / По центру / Справа) и размера.
* **Надежная работа:** Приложение может работать в двух режимах отслеживания окон: классический надежный `Foreground Service` (с использованием `UsageStatsManager`) или мгновенный `AccessibilityService` (Служба спец. возможностей).
* **Поиск приложений:** Удобный встроенный поиск с фильтрацией при выборе приложений для оверлея.

* **Встроенный Файловый Менеджер:** Однопанельный файловый менеджер в стиле MaterialFiles.
    * Выдвижное боковое меню с возможностью быстрого перехода (Внутренняя память, Root) и заглушками для сетевых дисков (FTP, SMB, WebDAV, Облако).
    * Расширенные файловые операции (долгое нажатие): Копировать, Вырезать (через системный буфер с кнопкой "Вставить" в верхнем меню), Переименовать, Удалить, Свойства (подсчет размера папок).
    * Встроенный просмотр файлов (открытие файлов одним нажатием через `FileProvider`).
    * **Интеграция с Shizuku:** Тихая установка файлов APK в один клик от лица системы/рута (pm install).

## 💻 Сборка вручную

Для сборки проекта на локальной машине с помощью Gradle выполните:

```bash
# Для отладочной сборки
./gradlew assembleDebug

# Для релизной сборки
./gradlew assembleRelease
```
