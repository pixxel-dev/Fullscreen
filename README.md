# Flyme Tweak (LynkCo Overlay App)

Это полностью переписанное, чистое Android-приложение для автомобильных магнитол (например, LynkCo). Оно создает на экране удобную плавающую кнопку-оверлей, которая позволяет быстро запускать выбранные вами приложения.

## 🌟 Основные функции

* **Плавающая кнопка (Overlay):** Кнопка всегда находится поверх всех остальных окон, чтобы вы могли быстро запустить нужное приложение из любой точки системы.
* **Настройка расположения и размера:** В настройках можно выбрать сторону экрана для отображения кнопки (слева или справа), а также настроить ее размер под себя с помощью ползунка (от 30 до 150 dp). По вертикали кнопку можно просто перетаскивать пальцем по экрану.
* **Мультивыбор приложений:** Вы можете выбрать сразу несколько приложений в настройках. При нажатии на кнопку появится удобное системное меню для выбора нужной программы.
* **Полноэкранный режим (Display 1003):** Двухступенчатая логика запуска для максимальной совместимости.
  1. Первое нажатие на кнопку открывает приложение в стандартном режиме и меняет иконку кнопки на знак `<>`.
  2. Второе нажатие принудительно разворачивает приложение на полный экран мультимедиа автомобиля (передавая параметр `LaunchDisplayId = 1003`).
* **Автозапуск:** Приложение автоматически стартует в фоне (Foreground Service) при включении магнитолы.
* **Отображение версии:** В меню настроек всегда отображается текущая версия сборки приложения.

## 🛠 Установка и Обновления

* Проект имеет настроенный конвейер сборки **GitHub Actions**. Каждый раз при внесении изменений автоматически собирается релизный APK-файл.
* Приложению жестко задан сертификат подписи (`keystore.jks`). Это означает, что вы можете бесшовно устанавливать новые обновления поверх старых прямо из GitHub, не удаляя приложение и не теряя ваши настройки.
* Благодаря включенной минификации (R8 / ProGuard), приложение очищено от мусорного библиотечного кода и весит всего ~2.5 МБ.

## 💻 Сборка вручную

Для сборки проекта на локальной машине с помощью Gradle выполните:

```bash
# Для отладочной сборки
./gradlew assembleDebug

# Для релизной сборки (с включенной оптимизацией R8)
./gradlew assembleRelease
```
