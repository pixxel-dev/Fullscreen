# Бэклог проекта (Планы на будущие релизы)

Ниже представлен список актуальных идей и крупных задач для реализации в будущих версиях приложения:

## 1. Наполнение вкладки "Твики" системными настройками через ADB / Shizuku
- Расширение списка доступных системных переключателей и настроек автомобильной медиасистемы.
- Отправка команд через Shizuku и ADB (управление плотностью экрана, анимациями, разрешениями приложений).

## 2. Адаптация подключения ADB для Android 11+ (TLS Pairing)
- Реализация пользовательского интерфейса для ввода 6-значного кода сопряжения и порта (TLS pairing) для работы с беспроводным ADB на Android 11+.
- Использование нативного компонента `NativeAdbHelper` для автоматического поддержания соединения.

## 3. Интеграция с облачными хранилищами в Файловом менеджере
- Реализация сервисов для прямого подключения к облачным хранилищам (Яндекс.Диск, Google Drive, Облако Mail.ru).
- Возможность скачивания конфигураций, медиафайлов и APK-файлов напрямую в память магнитолы.
