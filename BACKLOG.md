# Бэклог проекта (Планы на будущие релизы)

Ниже представлен структурированный список задач и идей для реализации в будущих версиях приложения.

## 1. Управление экраном и отображением
- **Индивидуальные профили приложений**: Настройка масштаба (DPI) и шрифтов не глобально для всей системы, а автоматически при запуске конкретных программ (через Accessibility Service).
- **Принудительный Immersive Mode**: Скрытие статус-бара и панели навигации для выбранных приложений, что полностью оправдывает название Fullscreen.
- **Управление частотой обновления**: Блокировка частоты обновления экрана (например, строго 90 Гц или 120 Гц) для выбранных игр, если это поддерживается ядром устройства.

## 2. Интеграция с ADB и Shizuku
- **Встроенный терминал**: Полноценная консоль для ввода и сохранения часто используемых ADB-shell команд прямо с устройства, используя существующий NativeAdbHelper.
- **Удаление системного мусора (Debloater)**: Интерфейс для заморозки (disable) или удаления предустановленных системных приложений без root-прав через интеграцию с Shizuku.
- **Менеджер разрешений**: Выдача скрытых системных разрешений (например, `WRITE_SECURE_SETTINGS`) другим приложениям в один клик.
- **Расширенные привилегии без Root**: Выполнение системных команд, глубокая настройка системы и тихий запуск системных утилит на закрытых магнитолах LynkCo.

## 3. Файловый менеджер и Установка
- **Извлечение APK (App Backup)**: Функция сохранения установочных файлов уже установленных на устройстве приложений с помощью `FileManagerFragment`.
- **Поддержка сетевых протоколов**: Доступ к файлам по FTP, SMB или WebDAV для беспроводного обмена данными с ПК напрямую через приложение.
- **Пакетная установка**: Возможность выделить несколько APK-файлов в менеджере и установить их фоном за один раз через `ApkInstaller`.
- **Интеграция с облачными хранилищами**: Прямое подключение к облакам (Google Drive, Яндекс.Диск, Облако Mail.ru, GitHub) для скачивания конфигураций, обоев, музыки и APK прямо в магнитолу.

## 4. Оверлей и плавающие элементы
- **Системный монитор**: Вывод компактного виджета с текущей загрузкой CPU, объемом свободной оперативной памяти, температурой батареи или счетчиком FPS через существующий `ForegroundOverlayService`.
- **Жестовое управление**: Назначение действий (назад, домой, недавние приложения, сделать скриншот) на свайпы по плавающим кнопкам.

## 5. Пользовательский опыт (UX)
- **Поддержка Material You**: Внедрение динамических цветов (Dynamic Colors) для Android 12+, чтобы интерфейс автоматически подстраивался под цветовую палитру обоев пользователя.
- **Резервное копирование конфигурации**: Экспорт и импорт пользовательских настроек (размеры кнопок, координаты оверлея, сохраненные порты ADB) в JSON-файл для быстрого восстановления после переустановки.
- **Настройка автообновления**: Проверка новых версий приложения через GitHub API, скачивание APK-файла и тихая/стандартная инициализация установки обновления.
