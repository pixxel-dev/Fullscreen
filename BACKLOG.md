# Бэклог проекта (Планы на будущие релизы)

Ниже представлен список крупных задач и идей для реализации в будущих версиях приложения:

## 1. Интеграция Shizuku или ADB-консоли
- Позволит приложению выполнять системные команды с повышенными привилегиями без необходимости полного Root-доступа (что особенно актуально для закрытых систем магнитол LynkCo).
- Даст возможность "тихой" установки обновлений, управления другими процессами и глубокой настройки системы.

## 2. Интеграция с облачными хранилищами
- Реализация сервиса для прямого подключения к популярным облакам по публичным ссылкам.
- Поддержка: Google Drive, Яндекс.Диск, Облако Mail.ru, GitHub.
- Идея: возможность скачивать конфиги, обои, музыку или APK прямо в магнитолу без использования флешек.

## 3. Встроенный файловый менеджер
- Разработка и настройка собственного (или интеграция легкого) файлового менеджера для управления скачанными файлами, кэшем и конфигурациями внутри системы.
- Удобный интерфейс, адаптированный под автомобильные экраны (крупные элементы).

## 4. Настройка автообновления
- Реализация системы проверки новых версий приложения через GitHub API (проверка тегов релизов).
- Автоматическое (или по кнопке) скачивание APK-файла.
- Инициализация установки обновления (через стандартный инсталлер Android или "тихо" через Shizuku, если будет реализован пункт 1).
