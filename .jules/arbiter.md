# Журнал Арбитра (Arbiter Log)

Этот журнал содержит записи о системных коллизиях в базе знаний, дублировании устаревших регламентов и принятых решениях по их устранению.

## 2025-10-02 - [Актуализация BACKLOG.md и стандартизация инструкций для агентов]
**В чем состояло противоречие:**
1. В файле `BACKLOG.md` (пункты 3 и 4) указаны задачи «Встроенный файловый менеджер» и «Настройка автообновления» как планируемые на будущее, тогда как в `README.md` и кодовой базе (`FileManagerFragment.java`, `MainActivity.java`, `ApkInstaller.java`) эти функции уже полностью реализованы.
2. Инструкции и памятки для ИИ-агентов находились внутри пользовательского `README.md`, при этом общепринятый файл регламентов `AGENTS.md` отсутствовал. Это создавало риск использования устаревших данных и смешения инструкций для пользователей и агентов.

**Решение:**
1. Из `BACKLOG.md` удалены уже реализованные задачи (Файловый менеджер и Автообновления), сохранены только актуальные планируемые улучшения.
2. Создан единый файл регламентов `AGENTS.md` в корне проекта с четкими правилами версионирования (Semantic Versioning X.Y.Z), языковыми нормами (строго русский язык) и правилами работы с кодом для автомобильной системы LynkCo (Android 12, Display ID 1003).
3. Из `README.md` вынесены специфичные для ИИ памятки в единый стандарт `AGENTS.md`.

## 2025-10-02 - [Фиксация стандарта чистоты кода и разделения утилит]
**В чем состояло противоречие:**
Риск разрастания классов ("God Objects") при добавлении новой функциональности без четкого регламента выноса логики в отдельные утилиты/контейнеры.

**Решение:**
В раздел 4 файла `AGENTS.md` добавлено явное правило о сохранении чистоты кода и обязательной изоляции каждой отдельной фичи/инструмента в специализированные утилиты и подпакеты.
