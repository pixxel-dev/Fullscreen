# AGENTS.md — Инструкции и регламент для ИИ-агентов

Данный документ описывает правила, стандарты архитектуры и процедуры взаимодействия ИИ-агентов при работе с кодовой базой **Flyme Tweak (LynkCo Overlay App)**.

---

## 🌐 1. Языковой стандарт
- **Строго русский язык**: Все ответы, пояснения, комментарии в коде, сообщения коммитов, описания Pull Request и записи в журнал должны оформляться на русском языке.

---

## 🛠 2. Семантическое версионирование (Semantic Versioning)
Проект использует стандарт `X.Y.Z` (Мажор.Минор.Патч):
- **Патч (`Z`)**: Инкрементируется при каждом стандартном релизе, отправке изменений, исправлении багов или небольших доработках (например, `1.0.5` → `1.0.6`).
- **Минор (`Y`)**: Инкрементируется при реализации крупных фич из `BACKLOG.md` (при этом `Z` сбрасывается в `0`, например, `1.0.5` → `1.1.0`).
- **Мажор (`X`)**: Изменяется только при полном переписывании архитектуры приложения по явному требованию пользователя.
- **Автоматический `versionCode`**: Формируется через GitHub Actions (`git rev-list --count HEAD`).

---

## 🚘 3. Специфика платформы и архитектуры
- **Автомобильная система**: Приложение разрабатывается для автомобильных головных устройств (в частности, LynkCo) под управлением Android 12 (API 31+) с двумя широкоформатными экранами.
- **Вторичный дисплей (`Display ID 1003`)**: При разворачивании приложений на весь экран система автомобильной медиасистемы отправляет приложение на виртуальный дисплей 1003. Плавающие кнопки (`ForegroundOverlayService`) дублируются с использованием отдельного контекста дисплея (`createWindowContext`), чтобы исключить их перекрытие.
- **Отслеживание активных окон**: Используется фоновая служба `ForegroundOverlayService` с периодичностью опроса `UsageStatsManager` в 1 секунду. Служба `OverlayService` (`AccessibilityService`) используется как опциональный ускоритель.

## 📂 4. Структура пакетов и порядок в коде
- Базовый пакет проекта: `com.flyme.fscrn`.
- Код должен размещаться по функциональным подпакетам:
  - `com.flyme.fscrn.ui` — UI-компоненты (MainActivity, кастомные Preferences).
  - `com.flyme.fscrn.filemanager` — Файловый менеджер (FileManagerFragment, FileAdapter).
  - `com.flyme.fscrn.installer` — Утилита тихого и стандартного инсталлятора APK (ApkInstaller).
  - `com.flyme.fscrn.adb` — Утилиты работы с ADB (NativeAdbHelper, LocalAdbHelper).
  - `com.flyme.fscrn.overlay` — Фоновые службы и интерфейс оверлея.
  - `com.flyme.fscrn.system` — Системные ресиверы (BootReceiver).
- **Запрет дублирования**: Не допускается наличие устаревших дубликатов классов в корневом пакете (все утилиты должны находиться в целевых подпакетах).

---

## 🔒 5. Безопасность и приоритет установки APK
- Иерархия выполнения вызовов с повышенными привилегиями для тихой установки пакетов:
  1. **Shizuku API**
  2. **NativeAdb** (Android 11+ TLS pairing / native `libadb.so`)
  3. **LocalAdb** (Java ADB сокет 127.0.0.1:5555)
  4. **PackageInstaller** (Стандартный интерактивный диалог системы AndroidX)
- Никакие ключи подписи и пароли от keystore не должны храниться в открытом виде в коде. Передача секретов релизной сборки осуществляется строго через переменные окружения CI/CD (`KEYSTORE_PATH`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`).

---

## 🖼 6. Графические ресурсы
- Для иконок приложения в `mipmap-*` используются стандартные статические PNG без векторных адаптивных икон (`Adaptive Icon`), чтобы избежать искажений на специфических лаунчерах авто.
- Внутренние элементы интерфейса приложения используют векторные drawable из Material Design.
